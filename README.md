Combined Analog and Digital Clock in Java
This Java project implements a real-time analog and digital clock using Java Swing and 2D graphics. The analog clock uses graphical hands to represent time, while the digital clock shows the time in HH:mm:ss format.
Features
- Analog clock with:
- Hour, minute, and second hands
- Clock face with 1–12 hour markings
- Digital clock display (24-hour format)
- Real-time updates every second
- Threaded for smooth time refresh
- Built using Java Swing (portable GUI)
